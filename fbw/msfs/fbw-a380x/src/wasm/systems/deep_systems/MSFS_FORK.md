# MSFS fork of the deep model

Since 30 Sep 2026 these files belong to the MSFS port. They started as a copy
of the X-Plane plugin's `src/deep` (vendored by `tools/sync-deep-systems.sh`),
and are now edited here, for MSFS, so the deep model can have authority over
FlyByWire's systems without touching X-Plane.

Do not run `sync-deep-systems.sh` against this checkout: it deletes this
folder and copies the X-Plane files back. The pre-fork copy is backed up in
`E:/fbw-backup/2026-09-30-msfs-authority-start/untracked.tar`.
Workspace rules: `D:/A380/msfs-a380/README.md`.
