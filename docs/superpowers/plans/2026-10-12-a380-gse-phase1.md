# A380 Ground Equipment, Phase 1 (GPU pipeline) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One accurate, hand-modelled ground power unit (TLD GPU-409-E-CUP, 90 kVA diesel). It appears beside the A380's nose with its cable plugged in whenever the flyPad's GPU button gives the aircraft ground power. Everything in the pipeline is reused for every later vehicle.

**Architecture:**
- A Blender 5.2 script builds the GPU to the manufacturer's dimensions and renders it beside its reference photos.
- The same script bakes one 2048 PBR texture set and exports X-Plane OBJ8 through our own exporter. `objdecimate` adds levels of detail.
- The plugin's new `gse.rs` loads the object only while the GPU is wanted. It places one instance on the ground in front of the receptacle and unloads it again.
- `efb.rs` stops summoning X-Plane's own GPU cart.

**Tech Stack:** Blender 5.2.2 (bpy, headless), Python 3 (exporter tests), Rust plugin (`E:/fbw-int/plugin`), XPLM instancing API, `tools/objdecimate`.

**Spec:** `E:/fbw-int/plugin/docs/superpowers/specs/2026-10-12-a380-ground-equipment-design.md`

## Global Constraints

- Everything we ship is made by us. GSX and other add-ons are looked at only. Reference photos stay in `D:/A380/gse-refs`, outside every repository.
- Dimensions come from manufacturer data. Any value estimated from photos is marked as estimated on the reference sheet.
- Positions come from the Airbus A380 Airport Planning document. External power is at 5.99 m aft of the nose, ±0.45 m from the centreline, 2.59 m above the ground (section 5-4-4).
- No agents. No explanatory comments in code. No git commits unless the user asks: back up instead (`E:/fbw-backup/2026-10-12-gse`). `CARGO_TARGET_DIR=D:/A380/fbw-build/target`. X-Plane is launched only when the user asks.
- Budget: 30–80k triangles at the closest level of detail, one 2048 texture set.

### Task 1: Reference sheet

- [ ] Find the TLD GPU-409-E-CUP datasheet and dimensioned drawing. Record:
  - overall L × W × H, wheelbase, track and wheel size;
  - drawbar, cable reel or outlet position, panel layout and colours.
- [ ] Collect at least 8 photos (front, rear, both sides, three-quarter views, control panel, cable outlet, wheels) into `D:/A380/gse-refs/gpu_tld409/`. Note each photo's URL on the sheet.
- [ ] Write the sheet. Mark every value not from the datasheet as estimated, with its method (for example, scaled from wheel diameter in photo 3).

### Task 2: Blender helpers and the GPU model

- [ ] `gselib.py`: the helpers listed above.
  - Units are metres. Blender axes: X right, Y forward, Z up. The origin is the ground point under the axle centre.
- [ ] `gpu_tld409.py`: build every visible part from the sheet's dimensions:
  - body with access doors and louvres, control panel with gauges and buttons;
  - drawbar and hitch, wheels with tyres and hubs, mudguards;
  - cable outlet, the 400 Hz cable and the plug;
  - lights and placards (generic text only).
  - Parts that move are separate objects named `anim_<part>`.
- [ ] Render the views matching the photos (`build.py --views`). Run `compare_sheet` and inspect it. Fix proportions until every view matches within what the photos can show.

### Task 3: Bake

- [ ] `bake.py`: UV-unwrap with Smart UV Project at a 0.004 margin, packed per collection. Bake:
  - albedo multiplied by ambient occlusion;
  - tangent-space normal from the bevels and the high-poly detail;
  - metal/gloss in the converter's `material_gloss` channel layout (read `msfs2xp::texture::material_png` first).
- [ ] Check the baked maps in a render of the low-poly model with only the baked textures.

### Task 4: OBJ8 export and LODs

- [ ] `test_export.py`, written first. Export a 2-part test collection with one `anim_` part, then assert:
  - `POINT_COUNTS` matches the VT and IDX counts;
  - every `ANIM_begin` has its `ANIM_end`;
  - texture lines name existing files;
  - triangle winding faces outward (normals agree with the face order).
- [ ] `export_obj8.py`: one `TEXTURE` with `normal` and `material_gloss` maps, `GLOBAL_specular 1.0`, `ATTR_no_shadow` off (the GPU casts shadows).
  - Each `anim_` object is exported inside `ANIM_begin` / `ANIM_rotate` or `ANIM_trans` blocks driven by its `fbw/gse/<name>` dataref.
- [ ] LODs: `objdecimate gpu.obj gpu_lod.obj 0:60:0.002:keep 60:300:0.01:prune 300:3000:0.04:sloppy:0.1`.
- [ ] Run the tests. They pass.

### Task 5: Plugin, loading and placement

  - The GPU stands 3.0 m forward and 2.5 m right of the receptacle, heading back towards it. The ground comes from `xp::probe_terrain`.
- [ ] Add the module to the `lib.rs` slots after `efb`.
- [ ] `cargo test gse`. Pass.
