# DOM, CSS and SVG usage recorded in Chromium

Generated by `npm run dom-usage` (tools/reference/src/dom-usage.mjs) from
`npm run reference -- --state all --record`. Do not edit by hand.

- States: cold-dark-powered
- Screens: CLOCK, PFD_L, SD

What this measures: every method and accessor on the DOM, CSSOM, SVG,
Canvas and animation interface prototypes was wrapped with a counter
while the real instrument bundles loaded and ran 20 s of frames in each
state. Calls are attributed to the first script on the stack, so only
calls made from the bundles are listed as instrument use. CSS properties
assigned as `el.style.name = v` are recorded through a proxy on `.style`.
The end-of-run sections walk the final document and the loaded style
sheets. Counts are summed over screens (maximum over states per screen).
Code paths a state does not reach (other SD pages, failures, other ND
modes) are not recorded; compare with docs/dom-survey.md, which is static.
